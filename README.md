# Zepto-SQL-Business-Analysis
# 🛒 Zepto SQL Business Analysis

This project analyzes a Zepto sales dataset using SQL to answer business questions and generate actionable insights.

## 🚀 Features

- Data exploration using SQL
- Sales analysis
- Customer behavior analysis
- Product performance analysis
- Business insights using SQL queries

---

## 🛠️ Tech Stack
- MySQL

## 📊 Analysis Performed

- Total Sales
- Best Selling Products
- Category-wise Sales
- Customer Purchase Analysis
- Revenue Insights
- Business KPI Queries
